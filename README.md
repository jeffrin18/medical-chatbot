# Medical Chatbot

A simple AI chatbot built using Python, Flask, TensorFlow, and NLTK.

## Steps to Run:
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Train the model:
   ```bash
   python train_model.py
   ```

3. Start the app:
   ```bash
   python app.py
   ```

4. Open [http://127.0.0.1:5000](http://127.0.0.1:5000) in your browser.
